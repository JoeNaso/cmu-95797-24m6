## Setup
To get started, you will need a local environment to run python. You can set this up by following these steps: 
1. Download this project to you computer. You will need git in order to do so. 
   1. Git setup: `TODO`
2. Download `uv`. This is an open-source package manager which will let you set up all of the project dependencies without effecting the rest of your computer's setup. 
   1. Windows: [Installation instructions](https://docs.astral.sh/uv/getting-started/installation/#__tabbed_1_2)
   2. Mac: [Installation instructions](https://docs.astral.sh/uv/getting-started/installation/#__tabbed_1_1)
      1. You can also use Homebrew on Mac to easily install, but this might require other updates
3. Run the setup script (You only have to do this once)
   1. In your terminal, navigate to the root of this project (the same folder this file resides) and run the following command: 
      1. `uv run ./scripts/start_project.py`
      2. Note: Running this script multiple times will be fine, but you only have to do this once! 
   2. This will create a virtual environment which can be access to run the project
      1. To use the virtual environment navigate to the project root. then:
         1. Windows: `.venv\Scripts\activate`
         2. Mac: `source ./venv/bin/activate`
